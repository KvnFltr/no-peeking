# Contributing

Thanks for helping make LLM forecasting results more trustworthy.

## Add a model to the leaderboard (10 minutes on a free GPU)

```bash
pip install -e ".[llm]"
nopeeking probe <hf-model-id> --config configs/v1.yaml --limit 2000   # add --dtype 4bit for 7B+ on a 16 GB GPU
nopeeking report --config configs/v1.yaml
```

Open a pull request with `results/v1/probe/<model>.json` and the matching
`results/v1/predictions/probe__*.parquet` (predictions only: a few hundred KB), and add the model to
`configs/models.yaml` with its public release month. Models released after 2025-06 are welcome too: they are listed,
but their post-cutoff score is flagged because part of the test period may predate their training data.

## Code

* `pip install -e ".[dev]"`, then `ruff check src tests`, `ruff format src tests` and `pytest` before pushing.
* Keep tests offline: network calls belong in `nopeeking.data` and are mocked or cached in tests.
* Results policy: every number a human reads (README, paper) is generated by `nopeeking report` from `results/`.
  Negative and null results are reported like any other.

## Data

EDGAR access must respect the SEC fair-access policy: declare a contact through `NOPEEKING_SEC_USER_AGENT` and keep
the default rate limit. Never commit raw prices.
